It has multiple clocks already on the board, DATA_CLK, FB_CLK, CLK_OUT and SPI_CLK are accesible to the FPGA. 

So we need a Linux distribution on the SD card and download the necessary drivers. Using cat to read and echo to write from /sys/bus/iio/devices/iio:deviceX, we can change things on the FPGA.
It is volatile, if we want permanent changes, we need a file that runs at startup.

IIO oscilloscope is used for data logging/live feed. For longer data logging on the FPGA, a Integrated Logic Analyzer is used, which captures signal transitions to a VCD file, which I can retrieve and then load into GTKwave.
